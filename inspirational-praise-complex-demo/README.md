# Inspirational Praise Complex — Demo Website

A multi-page static school website built with plain HTML, CSS and JavaScript.

## Pages
- Home
- About
- Academics
- Admissions
- Gallery
- News & Events
- Contact

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash stock images

There is **no backend, database, PHP, Node.js or Supabase**.

## Run locally
Open `index.html` in a browser.

For the best development experience, use VS Code with Live Server, or upload the folder to GitHub Pages.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders.
3. Go to Settings → Pages.
4. Select the main branch and `/root`.
5. Save and wait for GitHub to publish the site.

## Customising the demo
Replace the stock image URLs in the HTML/CSS with the school's real photos.

Update:
- School logo
- Motto
- School history
- Curriculum/classes
- Admission requirements
- Fees
- Email address
- Social media links
- News/events
- Gallery images

The contact page uses phone/WhatsApp links and does not store form submissions. The demo enquiry form is intentionally frontend-only.
